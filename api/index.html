API ouverte

Toutes les données de l'agenda sont libres (licence CC BY 4.0 : réutilisation libre, y compris commerciale, en citant « Agenda culturel Tunis »). Pas de clé, pas d'inscription : ce sont des fichiers mis à jour chaque jour, lisibles depuis n'importe quel site (CORS ouvert).

Fichiers

AdresseContenu
/api/v1/evenements.jsonTous les événements à venir, toute la Tunisie
/api/v1/lieux.jsonLes lieux, avec coordonnées quand on les connaît
/api/v1/sources.jsonLes sources lues et leur état
/agenda.icsLe calendrier, à ajouter dans Google Agenda, Apple Calendrier ou Outlook

Adresse complète : {{ '/api/v1/evenements.json' | absolute_url }}. Les champs de la version 1 ne changent pas ; une nouvelle version aura une nouvelle adresse.

Un événement

ChampDescription
idIdentifiant stable tant que le titre et la date ne changent pas
titreDans la langue de la source
debut2026-11-21T20:30:00+01:00 si l'heure est connue, sinon 2026-11-21
finDernier jour (expos, festivals), sinon null
categorie{% for c in site.data.categories %}{{ c[0] }}{% unless forloop.last %}, {% endunless %}{% endfor %}
lieunom, adresse, ville ({% for v in site.data.villes %}{{ v.id }}{% unless forloop.last %}, {% endunless %}{% endfor %}), fiche
prix, gratuitTexte du prix (« 20 DT », « Gratuit ») et booléen
en_famille, commercial, filmBooléens. commercial : cours, yoga, brunch…
seancesPour un film ou un spectacle joué plusieurs jours : les dates
fiche, lienFiche sur l'agenda, page d'origine
source, autres_sourcesD'où vient l'événement ; s'il a été vu ailleurs (billetterie…)
imageAffiche, si on en a une
ajoute_leDate d'arrivée dans l'agenda

Exemple

fetch('{{ '/api/v1/evenements.json' | absolute_url }}')
  .then(r => r.json())
  .then(d => d.evenements.filter(e => e.lieu.ville === 'sfax' && e.gratuit))
  .then(console.log);
